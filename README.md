# AI Insights - Bootstrap Demo

This folder contains a two-page responsive website for Question 5 of the Week 7 assignment.

## Pages
- `index.html` - landing page introducing practical uses of AI.
- `comparisons.html` - overview and side-by-side comparison of Claude, ChatGPT, and Gemini.
- `css/styles.css` - custom styling layered on top of Bootstrap.

## Template inspiration
The layout and responsive business-site structure are inspired by Start Bootstrap's free **Modern Business** template:
https://startbootstrap.com/template-overviews/modern-business/

This is a student-customized implementation using Bootstrap 5 via CDN, rather than a copy of the original template package. Start Bootstrap lists its free themes and templates here:
https://startbootstrap.com/themes

## How to view
Open `index.html` in a web browser. Use the navigation bar to move between Home and AI Tool Comparisons. An internet connection is needed to load the Bootstrap CDN files.
